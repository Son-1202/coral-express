# T-07 — DEV: bots + `scripts/balance.ts` (E1 headless balancing harness)
**Role:** DEV · **Effort:** high · **Phase:** 3
**Owned paths:** `src/bots/**`, `scripts/balance.ts`, `scripts/balance/**`, `tests/unit/bots/**`, `docs/qa/balance_report.md`
**Read first:** CLAUDE.md, pm/STATE.md, docs/content/SPEC.md section "E1", `src/sim/README.md`, docs/content/GDD.md.

## Goal
Bots that play the sim headlessly and a harness that measures every E1 target. **Do not tune data** (CONTENT owns `src/data`; tuning is T-14). Report honestly.

## Deliverables
1. `src/bots/` (pure TS, no DOM; also used by `window.__debug.runBot(name)` later): `random`, `greedy`, `bondNever` per SPEC E1. Common `Bot` interface `{ name; decide(sim, t): Action[] }` called once per sim-second (feed + sight taps happen on their own cadence). Greedy: evaluate every affordable action by Δ(total Shells/s incl. fare rate) / cost (use sim cloning or analytic marginal estimate — must be fast), place fish to complete pairs/communities in correct habitat (move fish when beneficial), buy track when its payback beats alternatives (value of next station = higher stationMult + new species), Depot Reset rule (projected ≥ 2× current total tickets; ≥ 3 first run), upgrades in table order, newest Line, Today's Special when payback better, requests on path, mascot = highest-level fish. Bond-never: same economy but never moves fish for bonds, places by raw output + habitat, spreads species randomly across carriages.
2. `scripts/balance.ts`: `npx tsx scripts/balance.ts [--games N] [--bot name] [--minutes 120] [--offline-at 30]` runs seeded games (default 5000 per bot; use `worker_threads` across CPU cores) for 120 sim-minutes of active play or until the Grand Terminus; also the "greedy + one 8 h offline break at minute 30" variant (uses `advanceOffline`).
3. Metrics (median + p10/p90 where relevant) for every E1 row: time to first reset (greedy, random + % not within 120 min), time to Terminus (greedy, greedy+offline → % sooner, bond-never → % slower / % not reached), bond-never income at minute 15 of run 1 vs greedy, first pair time, requests income share, max gap between meaningful goals in minutes 5–15 of each run, fare share of total income, max single-species income share at each reset, % runs each species bought before Terminus, longest dead time after minute 1, number of resets before Terminus.
4. Writes `docs/qa/balance_report.md`: table of metric / target / value / PASS-FAIL, plus a short diagnosis paragraph of the biggest misses (what in the data causes it). Also writes `docs/qa/balance_report.json`.
5. Quick mode `--games 200` must finish in < 2 min; full 5000 in < 20 min.
6. Unit tests: bots never throw and never take illegal actions over a 10-min game; greedy beats random on income at minute 15.

## Acceptance
Harness runs and produces the report (targets may be red — that's T-14's job). Report the headline numbers.
