# T-01 — DEV: scaffold + side-on diorama renderer (placeholder art)
**Role:** DEV · **Effort:** medium · **Phase:** 1
**Owned paths:** `package.json`, `package-lock.json`, `tsconfig*.json`, `vite.config.ts`, `index.html`, `vercel.json`, `src/**` (NOT `src/data/**`, NOT `src/story/**`), `scripts/**`, `tests/unit/**`
**Read first:** CLAUDE.md, pm/STATE.md, docs/content/SPEC.md sections B7, B9, C.

## Goal
A Vite + TS strict project that builds and shows the HD-2D side-on coastal diorama with a placeholder train that moves between stations, stops, and moves again, with true parallax and post-FX. No game rules yet (sim comes in T-04).

## Deliverables
1. `package.json` scripts: `dev`, `build` (`tsc --noEmit && vite build`), `preview`, `test` (`vitest run`), `shots` (Playwright screenshot script). Deps: three, postprocessing, howler, @fontsource/pixelify-sans, @fontsource/silkscreen. Dev deps: typescript, vite, vitest, tsx, sharp, @types/three, @types/howler. Run `npm install`.
2. `src/main.ts` boot; `src/assets.ts` manifest: map logical keys (e.g. `scenery.l1.far`, `train.locomotive`, `fish.clownfish`) → URL under `/assets/...` (served from repo `assets/` via Vite `publicDir: 'assets'` or equivalent so `assets/x.png` is at `/x.png` — pick one, document it in the file). Loader returns a procedural canvas placeholder texture when a file is missing (never crash).
3. `src/render/diorama/`: perspective camera (narrow FOV ~20–25°, slight downward tilt), layers as textured planes at different Z: far (sky gradient + sea + far cliffs), mid (cliff houses), track (rails + sleepers + train + station platforms), near (fences/poles/flowers). Placeholder textures are procedurally painted canvases in the Sunny Coast palette (pastel houses, turquoise sea, lemon trees) — make it look intentional, not grey boxes. Layers tile horizontally and scroll; parallax must come from real Z depth.
4. `src/render/train/`: placeholder locomotive + 3 glass tank carriages (seafoam green/cream, brass trim) built from planes/canvas; train moves along X with ease-in/ease-out, stops 6 s at a station platform, departs again (leg ~45 s; add `?fast=1` to make it 5 s for testing). Camera follows the train with easing and a small sway. Wheels rotate with speed. Carriages rock slightly.
5. `src/render/post/`: pmndrs postprocessing composer: tilt-shift DoF (TiltShiftEffect), bloom (soft), vignette, subtle noise; per-region color grade hook (simple LUT or color-matrix uniforms) with a `setTimeOfDay(t)` stub. Quality: High/Low; auto-drop to Low when FPS < 45 for 3 s.
6. Layout: fullscreen canvas, landscape 16:9-friendly, responsive. DOM HUD skeleton in `src/ui/` (top bar with placeholder Shells / Shells/s / Tickets / progress bar; bottom bar with Market · Track · Stamps · Depot buttons ≥ 44 px) using fonts Pixelify Sans (headings) and Silkscreen (numbers). Portrait phones show a "rotate your phone" card with a looping mini train (CSS).
7. `src/util/format.ts` `formatNumber(n, mode='short'|'scientific')`: 1.2K, 3.4M, 5.6B, 7.8T, 9.1Qa, 1.2Qi, … scientific from 1e18. Unit tests in `tests/unit/format.test.ts`.
8. `scripts/shots.ts`: starts `vite preview` (or uses a passed URL), opens with Playwright at 1280×720 and 844×390 (phone landscape) and 390×844 (portrait), waits 3 s, saves PNGs to `docs/qa/screens/T-01_*.png` (deviceScaleFactor 1).

## Acceptance
- `npm run build` 0 TS errors; `npm run test` green.
- Screenshots show a readable, attractive diorama with train, layered parallax, tilt-shift blur at top/bottom, HUD bars; portrait shows rotate card.
- No console errors.

## Out of scope
Game rules, real art, Tank View, audio.
