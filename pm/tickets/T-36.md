# T-36 — DEV: Export / Import save (protect progress when reinstalling the home-screen app)
**Role:** DEV · **Effort:** high · **Phase:** post-ship feature (producer need)
**Owned paths:** `src/game/storage.ts`, `src/game/controller.ts` (only the API surface for export/import), `src/ui/settings.ts` (+ a new `src/ui/saveTransfer.ts` if useful), `src/ui/types.ts` (GameApi additions), `tests/unit/game/**`, `tests/unit/ui/**`
(T-35 is editing `index.html`, `src/render/depot/**`, `src/assets.ts` in parallel — do not touch those.)
**Read first:** CLAUDE.md, pm/STATE.md, `src/game/storage.ts` (SAVE_KEY `coral-express.save`), `src/sim` `migrateSave`, `src/ui/settings.ts`.

## Why
Saves live in localStorage. On iOS a home-screen web app (standalone) has its own isolated storage; T-35 makes the app standalone, so the producer's progress won't carry into a freshly added icon. The producer must be able to move the save.

## Build
1. **Export:** Settings → "Save code" section → "Copy save code" button: serialize the current save (force a fresh `serialize()` first), wrap as `{v, savedAt, data}` → JSON → compress (CompressionStream 'gzip' when available, else none) → base64url, prefixed `CE1.` (or `CE0.` uncompressed). Copy to clipboard (`navigator.clipboard.writeText`, fallback: select-all text area). Also "Download save file" (`coral-express-save-YYYYMMDD.txt`) via Blob for desktop.
2. **Import:** "Load save code" → textarea (paste) or file picker → decode/validate (prefix, base64, JSON, version) → run `migrateSave` → show a preview card (Tickets, Lines opened, Shells, last saved time) → double confirm "Replace current progress?" → write to localStorage and reload the game state (or `location.reload()`). Invalid code → friendly error, current save untouched.
3. Also add a one-line tip under the section: "Moving to a new home-screen icon or device? Copy your save code first, then paste it there."
4. Touch targets ≥ 44 px, pixel-font styling consistent with Settings, works on phone landscape.
## Tests
Round-trip (export → import gives identical serialized state), compressed + uncompressed codes, corrupted code rejected without touching the existing save, old-version save migrated.
## Acceptance
Build + tests green; real-game check with Playwright: export code from a progressed game, clear localStorage, import, verify Tickets/lines/shells restored; screenshots `docs/qa/screens/T-36_settings_{1280,844}.png`, `T-36_import_preview.png`. Look at each with Read.
