## Goal
Pure deterministic TS game-rules engine. No DOM/Three/window. All numbers from `src/data` (pass `GameData` in; never import JSON inside sim except via an injected data object, so balance can swap data).

## API (implement; document in `src/sim/README.md`)
```ts
createSim(data: GameData, opts: { seed: number; save?: SaveData; now?: number }): Sim
interface Sim {
  readonly state: SimState;              // plain serialisable object
  advance(seconds: number): void;        // fixed 0.25 s ticks with remainder accumulator
  act(a: Action): ActionResult;          // { ok: true } | { ok: false, reason }
  price(a: Action): number | null;       // cost of an action (null = not purchasable)
  drainEvents(): SimEvent[];             // events since last drain (render/UI consume)
  stats(): { fishSps: number; farePerArrival: number; fareSps: number; totalSps: number };
  carInfo(carId: string): CarInfo;       // income, appeal, active bonds, possible bonds (missing partner ids), capacity used/total
  serialize(): SaveData;                 // version field; JSON-safe
}
```
- `SimState`: time, rngState, shells, runShells (earned this run), lifetime stats, currentLine, builtStations (per run), train {fromStation, toStation, phase 'moving'|'stopped', t, dir}, carriages [{id, habitat, slots, extraSlots, fish:[fishId], decor:[placed], cosmetics, heritage:boolean}], fish map {id, species, level, shiny, spent, carId, nickname?}, copiesOwned per species (this run), speciesBoughtThisRun, frenzy per car {activeUntil, cooldownUntil}, permanent block {tickets, totalTicketsEarned, upgrades[], openedLines[], stamps[], postcards[], mascot?, oldFriend streak, endless, reachedTerminals}, modifiers (active timed buffs for T-06 sights).
- `Action` union: buyFish{species, carId}, levelFish{fishId, times|'max'}, sellFish{fishId}, moveFish{fishId, carId}, buyCarriage{habitat}, changeHabitat{carId, habitat}, buySlot{carId}, buildTrack{}, feed{carId}, buyDecor{decorId}, placeDecor{carId, decorId, x, y, layer:'back'|'front', scale, flip}, moveDecor{carId, index, ...}, removeDecor{carId, index}, setCosmetic{carId, kind:'sand'|'backdrop'|'paint', value}. (T-06 will add: tapSight, buySpecial, acceptRequest, depotReset, buyUpgrade, chooseLine.) Design the union so T-06 extends it cleanly.
- Rules exactly per SPEC: costs (copy growth, level growth, carriage cost × fareMult_line, slot cost, habitat change 20%), species availability (first sale only at home station market: the train must have *arrived* at that station in this run → `marketStation` in state = station of last arrival; Catalogue = species bought this run), first pebble damsel free, levels 1–50 + milestones, habitatMult (whale always home, mascot ignores penalty — leave a hook), bonds (pairs: a fish counts toward at most one pair; deterministic matching; communities +100% & +5 appeal, community also counts its pairs; decor `bondBonusPP`), decor effects (same-id effects don't stack per car; appeal does; capacity), krill counts 2 for appeal, whale +5% all fish per distinct species on train, frenzy ×3 for 10 s (brass diver 15 s), 30 s cooldown, fares at every arrival = Σ appeal × 8 × stationMult × fareMult_line × ticketMult × upgrade mults, ticketMult = 1 + 0.10 × totalTicketsEarned.
- Train: starts at station 1, track built to 2; shuttles back and forth between 1..builtMax; leg = legSeconds (upgrade hook), stop = stopSeconds; emits `depart`, `arrive {station}`, `fare {amount}`. Building track to k: cost per SPEC; when the Line terminal (6) is first reached in a run → `terminalReached`; first time on Line 1/2 → opens next line (`lineOpened`); Line 3 first time → `ending` event and endless flag (fares ×2 permanent).
- Stamps: first visit of a station, first purchase of a species, shiny species → `stamp` event. Postcards unlocked on first station visit (`postcard` event with stationId).
- Shiny roll on every fish purchase using the seeded RNG (mulberry32 or similar; RNG state lives in SimState so save/load is deterministic).
- Events typed union incl. `purchase`, `levelUp`, `milestone`, `bondFormed`, `bondBroken`, `frenzy`, `arrive`, `depart`, `fare`, `trackBuilt`, `lineOpened`, `terminalReached`, `stamp`, `postcard`, `ending`, `income` (not every tick).

## Tests (`tests/unit/sim/*.test.ts`, Vitest)
- Tick invariance: same seed, scripted state (a few fish/cars), `advance(600)` once vs 2400 × `advance(0.25)` vs 7 × uneven chunks → shells within 0.1%.
- Costs/formulas: copy cost, level cost, milestone, carriage, slot, track, fare formula with known numbers.
- Bonds: pair, one-fish-one-pair rule, community counting pairs, habitat penalty, whale rule, krill appeal.
- Train: arrival cadence, shuttle reversal, terminal → line opening.
- Determinism: two sims same seed + same actions → identical serialize().
- Save round-trip: serialize → createSim({save}) → identical behaviour.
