## Asset folders convention (PM decision)
- `assets/_raw/` — raw Higgsfield downloads (gitignored).
- `assets/_cut/<path>.png` — ART's cleaned hi-res cutouts with alpha (max 768 px on the long side), committed. Same relative path as the final asset.
- `assets/<path>.png` — final game assets produced by the scripts below.

## Deliverables
1. `scripts/pixelize.ts` (sharp): `npx tsx scripts/pixelize.ts [glob...]` processes `assets/_cut/**` sprite groups → `assets/**`:
   - Per-group target size from a config table in the script (long side in px): fish 64 (pocket_whale 96, ghost_ray 80, krill 56), shiny same as base, plants 72 tall, decor 64, passengers 48 tall, wildlife 64, props 96, foliage 96, sights 80 (whale 160), icons 32, wheel 32, rod 48, locomotive 320 wide, car_shell 288 wide, station 384 wide. Unknown → 64.
   - Steps: trim transparent borders → downscale with area averaging (kernel `nearest` after a pre-blur-free `lanczos3` to 2× then `nearest`? pick what looks crisp) → alpha threshold (α<0.5 → 0, else 1) to kill halos → palette quantize (e.g. 24–32 colors, keep transparency) → 1 px dark outline (darkened average of neighbour colour, or #1d1a2a at 85%) around the opaque silhouette → write PNG.
   - Deterministic; idempotent; prints a table of outputs.
2. `scripts/optimize-assets.ts`: for painterly layers (scenery, interiors, backdrops, key art, postcards, line covers, style bible, station if not pixelized): `assets/_cut/<path>` or `assets/_raw` source → resize to max width (scenery 2560, interiors/backdrops 1280, key art 1920, postcards 960) → PNG with `palette: false`, compressionLevel 9, plus write a `.webp` sibling (quality 86). The game loader (DEV) may prefer webp.
3. Unit test with a tiny synthetic image (sharp-created) proving: halo removed, outline added, size respected.
4. Write a short `docs/art/PIPELINE.md`? No — ART owns docs/art. Instead put usage in the script header comment.
