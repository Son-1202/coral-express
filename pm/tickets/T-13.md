## Goal
Replace the T-01 placeholder driver (`src/render/placeholder.ts`) with the real sim, and make every sim event visible.

## Deliverables
1. `src/game/controller.ts`: owns the Sim (`createSim(loadGameData(), {seed, save, story})`), fixed 0.25 s tick loop from rAF, offline handling (on load: `advanceOffline(elapsed)`; on `visibilitychange` hidden→visible or a frame gap > 5 s → offline), autosave to localStorage every 10 s + on `pagehide` + after depot reset, save `version`/migration via sim's `migrateSave`. Event bus: drains `sim.drainEvents()` each frame and dispatches to render + UI subscribers.
2. `src/game/api.ts`: the contract the UI uses. Implement exactly the interface T-14 defines in `src/ui/types.ts` (`GameApi`); if that file does not exist yet when you start, create `src/game/api.ts` with: `{ sim, data, story, act(a), price(a), on(type, cb), off, getSettings(), setSettings(p), selectCar(id), selectedCar(), enterTankView(carId), exitTankView(), debug }`, and coordinate by reading `src/ui/types.ts` before you finish — **T-14's `GameApi` type wins**; adapt.
3. Render driven by sim state: train composition = sim carriages (habitat interiors from real art `train/interior_<habitat>.png`, car shell art, locomotive art, wheel/rod art when present; placeholders otherwise), up to 8 cars; fish sprites = sim fish (real `fish/<id>.png`, `_shiny` variant tinted fallback); train motion = sim train phase/progress (arrive/stop/depart), shuttling: visually keep the train always heading right and scroll the world (simplest: world scroll direction follows the sim direction but the locomotive stays at the front — choose the option that looks best, document it). Stations: real `station/l<line>.png` art; station name sign (DOM label or canvas texture) from `src/story/stations.json`.
4. Scenery from real art per current Line (`scenery/l<n>_{far,mid,near}.png`, foliage/props/wildlife sprites when present) with the parallax rig from T-01; line change swaps the set.
5. Event VFX (`src/render/fx/`): bond heart-bubble floating between partner fish (`icons/heart_bubble.png` or procedural) + dotted outline of a missing partner (from `sim.carInfo().possibleBonds`); `fare` coin burst from cars to HUD; `purchase` bubble pop + fish drop-in splash; `levelUp` white flash + sparkles; `milestone` bigger burst + small screen nudge; `frenzy` cooldown ring on the car door + food flakes; shiny sparkle; passengers (sprites `passengers/p1..p12`) walking on the platform at arrivals with bob/lean, boarding, cheering (jump+squash) at shinies/bonds/requests; Sights: dolphin race, gull on roof (clickable — calls `act({type:'tapSight'})`), whale breach (camera eases out), festival bunting + confetti, stowaway splash (clickable), sea fog (fog density up).
6. Input on the canvas: tap car = feed; long-press/right-click = `selectCar` + open car detail (emit UI event); double-tap = enter Tank View (calls T-15 hook `enterTankView`, no-op if absent); drag/scroll pan; drag a fish from one car to another = `moveFish`; keyboard ←/→, 1–8, Space (feed best car), Enter.
7. `window.__debug`: `seed`, `skipTo('line2'|'line3'|'depotReset'|'terminal'|'ending')`, `forceWin()`, `runBot(name)` (uses `src/bots` if present, else no-op with warning), `addShells(n)`, `fastForward(s)`, `triggerSight(id)`, `simulateOffline(s)`, `setTimeOfDay(t)`. Implement skipTo via sim helpers or by scripted fast-forward with a greedy-ish script.
8. Time-of-day 6-min cycle feeding `setTimeOfDay`; station lamp point lights at dusk/night.
9. Build hygiene (D-016): postbuild removes `dist/_cut`, `dist/_raw`, `dist/style_bible.png`. Lazy-load audio/video later; keep initial JS reasonable (code-split three/postprocessing if > 700 kB).
