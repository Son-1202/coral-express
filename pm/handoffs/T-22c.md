# T-22c handoff — UI typography, phone layout, depot guard, endless toast

## Done
- **Bug 1 (ligatures):** `hud.css` turns ligatures off on every element (`font-variant-ligatures: none` plus `font-feature-settings: "liga" 0, "clig" 0, "dlig" 0`, which the `font:` shorthand does not reset). "Clownfish", "first" and "Free fish slot" now render correctly in the real game too.
- **Bug 1 ("C" reads as "O"):** Pixelify's 600/700 weights close the C. New rule in the `panels.css` typography guard: text under 20px uses weight 400 (headings get size and colour instead), 600 only at 20px and up, no 700 under 28px. `.ui-sec` and `.ui-item-name` are now 17px (15px on phone). `.hud-btn`, `.ui-brass`, tabs and segment buttons use weight 400.
- **Bug 2 (UI part):** the Depot Reset button is disabled when `projectedTickets() === 0`, with the hint "Earn more Shells for at least 1 Ticket." shown in the card, under the button and as the button title. This is the pure `depotResetHint()` in `helpers.ts`.
- **Bug 9:** below 900px wide, at most 2 toasts show and they dismiss ×0.6 faster (`toastLimits()` in `toasts.ts`). The compact cards are at most 30vw wide.
- **Bug 10:** every control is at least 44×44 at 844×390. Fixed: `.ui-close`, `.ui-cog`, `.ui-tab`, `.ui-carchip`, `.ui-sell`, `.ui-move`, `.ui-link` and `.ui-input`. A Playwright audit over all panels, tabs and modals found 0 violations. The HUD station label is one line with an ellipsis.
- **Backlog:** `UiHandle.toast(title, text?, ms?)`. On the `ending` event the UI waits until `.ending` closes, then shows the "Endless mode" toast using `story/ending.json` `endlessToast`. The market "+N/s" now comes from `fishGainWithBonds()`, which uses `sim.carInfo().possibleBonds` (pair and community) and adds a "+bond" chip. Unit tests check it against the real sim income delta.
- **Harness:** new query params `&depot0=1`, `&toasts=N` and `&ending=1`.
- **Tests:** `tests/unit/ui/t22c.test.ts` (6 tests). All 163 tests pass, and tsc reports no errors.
