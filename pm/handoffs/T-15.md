## How T-13 wires it
```ts
import { createTankView } from './render/tank/tankView';
const tank = createTankView({
  renderer: stage.renderer,
  api: { data, state: () => sim.state, act: (a) => sim.act(a), carInfo: (id) => sim.carInfo(id) },
  getCarScreenRect: (carId) => /* CSS px rect of that carriage's tank on screen */ null,
  onExit: () => {/* re-enable train input */},
});
// frame loop:
if (!tank.isCovering()) stage.frame(dt);
tank.update(dt);
tank.render();
// optional: for (const e of events) tank.onEvent(e);   // level-up flash, frenzy wiggle
// double-tap carriage / Enter → tank.enter(carId)
```
- The view draws its own scene on top of the train frame, inside a scissor rect that animates over 0.8 s from `getCarScreenRect` to full screen. Without that callback it starts from a centred rect.
- While active, the tank's DOM overlay (z-index 40) takes all input.
- Esc, E and P are handled in the capture phase and call `stopImmediatePropagation`.
- Slosh is detected from changes in `state.train.phase`, so it works without event forwarding.

## Behaviour notes
- **Nicknames:** the sim has no nickname action, so nicknames are stored locally in `coral.tank.nicknames`. The card shows `fish.nickname` first if the sim sets one.
- **Pinned photos:** saved in localStorage under `coral.stampbook.photos` as `{at, carId, frame, dataUrl}`, up to 12. The stamp book (T-14) can read them with `readPinned()`.
- **Drop rule (`snapPlacement`):** the bottom strip is the front band, the floor goes to the back band at the floor line, and anything higher hangs on the wall (back band).
- **Motion:** the whale uses glider with a sinuous tail. The `sinuous` profile has no species, so the zoo shows a demo cell for it.
- **Not done:** fish do not route around decor or hide in the castle (SPEC "fish route around decor"), and the pistol-shrimp snap particle is missing.
