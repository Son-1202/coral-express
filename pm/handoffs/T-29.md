# T-29 handoff — no placeholder or overflowing item icons (DEV)

**Status:** done. Build green; `npm run test` 33 files / 197 tests green (new `tests/unit/ui/t29.test.ts`).

## Fixes
1. **Plant decor showed a procedural leaf.** New pure resolver `decorArt(data, id, exists)` in `src/ui/art.ts`. It uses the same precedence as the Tank View tray (`render/tank/models.ts iconFor`): `plantId` from decor.json (or a plant id) resolves to `plants/<plantId>`, then `decor/<id>`. The mappings are seagrass_tuft→reef_3, sea_fan→reef_1, kelp_strand→kelp_1 and tube_garden→vent_1. `decorIcon(data, id, size)` moved from `dom.ts` to `art.ts` and is used by the Market Decor tab, the Catalogue restock list and request rewards.
2. **Turtle Grass overflowed its box.** The cause was `.ui-fish`/`.ui-decor`: they are inline-grid with an auto track, so `max-height:100%` never resolved. Changes:
   - `panels.css`: `grid-template: minmax(0,1fr)/minmax(0,1fr)`, `overflow:hidden`, `box-sizing:border-box`. Decor/plant images use `width/height:100%`, `object-fit:contain` and `object-position:50% 100%` (bottom-aligned). Fish keep `max-*` sizing, which now resolves (no upscaling change).
   - `tank.css`: the tray `.tk-item img` is now a fixed 52 px square with contain, bottom-aligned, and `overflow:hidden`.
3. **Shells/s HUD icon was a blue circle.** `hud.ts` now uses `iconHtml('shells_per_sec', '<i class="wave"></i>')`. ART's `assets/icons/shells_per_sec.png` landed at 13:49 and the build's asset list picks it up; the screenshot shows the painted icon. The fallback branch is unit-tested.
4. **Audit: fixed (real art now used where it exists)**
   - The Today's Special medallion shows a fish sprite: the species for `levelDiscount` and the shiny target for `shinyEgg`. The `levelDiscount` badge text now comes from `config.todaysSpecial.levelDiscount`; it was a hard-coded CSS `'−30%'`.
   - Requests tab: a reward of `decor` shows the decor thumbnail.
   - Toasts:
     - `requestCompleted` shows the passenger portrait (looked up by `requestId`).
     - `depotReset` shows `icons/ticket`.
     - `sightEnd` shows `sights/dolphin|gull|whale` via a new `sightArt()`.
     - These use the new `spriteBox()`, which is a contained square.

After the fix it passes for all Market tabs, toasts and 38 tray items, with no console errors.
