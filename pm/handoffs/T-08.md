## Notes / decisions
- Final measured side == target exactly (content scaled to target−2, 1 px outline added). Never upscales.
- Size is measured after trimming at α≥0.5, so soft halos don't shrink the sprite.
- Outline adds colours beyond the 32-colour palette (by design: per-edge dark tint).
- Unknown paths → 64 px sprite. Icons recognised in `icons/` or `ui/{icon_,upgrade_,tab_,shell,ticket,stamp}`. ART should confirm final icon paths.
- optimize-assets defaults to `assets/_cut` only (`_raw` holds unchosen candidates; output name = source name).
