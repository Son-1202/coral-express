# T-01 handoff — DEV: scaffold + side-on diorama renderer

**Status:** done. `npm run build` passes with 0 TS errors. `npm test` is green (51 tests, including other tickets' tests). `npm run shots` exits 0 with no console errors.

## What exists
- Configs: `package.json` (scripts dev/build/preview/test/shots), `tsconfig.json` (strict), `vite.config.ts`, `index.html`, `vercel.json`.
- **Assets:** `publicDir: 'assets'`, so `assets/x.png` is served at `/x.png`. `src/assets.ts` maps manifest keys to URLs. A `virtual:asset-list` plugin in `vite.config.ts` lists the files that exist, so missing art is never requested (no 404s) and the procedural placeholder stays in use.
- `src/render/diorama/`: camera rig with FOV 22° and 4° tilt, easing, sway and drag/wheel pan.
  - Scenery is made of real-Z `TileLayer`s: sky + clouds, sea shader, far headlands, mid cliff village, mid islets, verge, track bed, rail, wall, garden, fence strip and lens foliage.
  - Stations repeat every 64 units.
  - All placeholder art is painted procedurally in `paint*.ts`, using the palette in `src/render/paint/palette.ts`.
- `src/render/train/`: locomotive plus 3 glass tank carriages.
  - Each tank interior is a shader: water, sand caustics, decor, plant sway and a water-line tilt that sloshes on brake and pull-away.
  - Fish are pixel sprites that mirror with a squash when they turn.
  - Wheels and rods turn with speed, carriages rock on rail joints from front to back, and steam puffs scale with speed.
  - `motion.ts`: 6 s stop, then an eased leg.
- `src/render/post/`: tilt-shift (own pass), bloom, grade (lift/gain/sat/warm with `setTimeOfDay`), vignette and noise. High/Low quality; `FpsGuard` drops to Low after 3 s below 45 FPS.
- `src/ui/hud.ts` + `hud.css`: ticket-style top bar, brass bottom buttons (44 px or more), and a portrait rotate card with a CSS mini train.
- `src/util/format.ts` with tests in `tests/unit/format.test.ts`; `tests/unit/ease.test.ts`.
- `scripts/shots.ts`: `npm run shots [-- <url>] [--query "..."] [--name X]`. It defaults to `quality=high`.

## URL params
- `?fast=1`: 5 s legs.
- `?quality=high|low`: locks quality (the default is auto).
- `?warp=N`: pre-advances N seconds.
- `window.__debug.setTimeOfDay('dusk')` and `setQuality`.
