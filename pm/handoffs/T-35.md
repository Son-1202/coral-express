# T-35 handoff — Depot Reset scene from T-34 art + app icon wiring (DEV)

**Status:** done. Build green, 241/241 unit tests (5 new in `tests/unit/game/depotArt.test.ts`).

## What changed
- `src/render/depot/depotArt.ts` (new, pure): finds the shed doorway (eroded dark blob, punched per column) and the pool's water band + largest all-water inner rectangle (closing + hole fill, so lily pads / caustics don't break it); siding slot maths. Unit-tested on synthetic images; on the real art: door 177×192 px at x 230, water inner 343×87 px.
- `depotLoad.ts` (new): own promise-per-path image cache (rebuild-safe), analysis canvases (shed with doorway punched; pool with water at 42 % alpha). Preload starts 3 s after boot (yard.png is 3.1 MB, kept off the boot path). If a reset happens before the art arrives, the painters are used and the set is rebuilt with the art while the white fade-in still hides it (t < 0.45 s). A failed load is forgotten and retried on the next reset (verified by aborting `depot/*` once). `disposeTree` frees the set + the scene's own Train on stop/rebuild (shared cached textures kept; `assets.ts` got `isSharedTexture`). Texture count no longer grows per reset from the depot (the remaining +2/reset also happens with the depot scene stubbed out → main-game resync, not T-35).
- `depotSet.ts` (new): Line far scenery (or `depot/backdrop_l<n>` if ART ever adds one) → yard strip (crates + siding sleepers) → siding rail (side-on, on the painted sleepers) + mirrored buffer stop → main rail (T-24 strip/0.11 unchanged) → shed (full copy behind the train, doorway-punched copy in front, camera-aligned so there's no parallax seam; door sill on the ballast, door = 1.32 × loco height; loco stops with its front half behind the wall) → Line wall + fenced meadow at main-game scale → pool. Every piece falls back to the T-19 painters.
- `poolFish.ts` (new): hop → splash droplets + ripple ring at the entry point → `FishView` with the species' T-15 motion profile inside the water rect (mover bounds + clamp of swarm companions), under the see-through water layer.
- `depotScene.ts`: uses the set; uncoupled cars roll to stacked slots against the buffer (lifted onto the siding; wheels on the siding rail head, pixel-scanned); uncoupled cars' wheels spin with their own roll and parked cars no longer rock while the loco leaves; `play(..., tod?)` picks `l<n>_far_{morning,dusk,night}` and tints the set + train to match (dusk/night checked by wrapping `play`).
- `overlay.ts`: compact caption on short (phone-landscape) screens so the shed roof stays visible.
- `src/assets.ts`: `PATHS.depot`, `depotBackdrop`, `sceneryFar`.
- `index.html`: favicons 32/16/ico, apple-touch-icon, manifest, apple web-app title/capable/status-bar (black-translucent), application-name; theme-color kept. postbuild doesn't touch `/app/`.
