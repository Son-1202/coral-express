# T-36 handoff — Save code export / import (DEV)

**Status:** done. Build green; 241 unit tests (25 new in `tests/unit/game/saveCode.test.ts`); real-game Playwright check passes.

## What
- Settings → **Save code**: tip line, *Copy save code*, *Download save file* (`coral-express-save-YYYYMMDD.txt`), *Load save code…*. The code is always shown in a read-only, selectable box after copy/download (manual fallback).
- Codes: `CE1.` = base64url(gzip(JSON `{v:1, savedAt, data}`)); `CE0.` = uncompressed (no CompressionStream). Whitespace/line breaks/quotes from pasting are ignored.
- Import dialog: paste or choose a file → **Check code** → preview table (this device vs code: Tickets, Lines opened, Shells, Stamps, Last saved) → *Replace current progress…* → 2 confirms → write → reload (drops `?new=1`/`?warp=`).

## Safety (the producer's save)
- Validated **before** `migrateSave`: prefix, base64, gzip, fatal UTF-8, JSON, wrapper `v`, `data.version ≤ SAVE_VERSION`, state with carriages, shells and tickets/openedLines. Then a dry-run `createSimInternal` (no offline time). Any failure = friendly error and storage untouched.
- `apply()` writes exactly the checked object. `replaceSave` copies the old save to `coral-express.save.backup`, writes, and reads it back. On failure the old save is kept.
- `controller.saveLocked` blocks autosave/pagehide/visibility saves after the write, so the old sim can't overwrite the import during the reload.
- Copy on iOS uses `clipboard.write(ClipboardItem(promise))` inside the tap, with writeText as a fallback and the visible code box as the last resort.
