# T-18 handoff — audio + Grand Terminus ending + cinematic player (DEV)

## Status: done (wiring into main.ts left to T-13 — snippet below)

## Files
- `src/audio/mix.ts`: pure helpers: playlist order, ambience per scene, self-crossfade scheduler (`nextLoopStart`/`loopSchedule`), equal-power gains, dB→gain, coin pitch (`coinSemitones` = 2·log10(amount), capped at 24 st), wheel-clack interval.
- `src/audio/music.ts`: `MusicPlayer` (Howler). Lazy: no Howl is created before `unlock()`. A Line plays `music_l<n>` and `music_main` alternately; Depot and ending are single loops. Ambience bed per Line. Every voice crossfades into its successor (music 2 s; ambience: amb_l1 3.5 s, others 2.5 s). Scene changes crossfade over 2 s. `duck(reason)` lowers music and ambience by −9 dB; the whale song ducks them while it plays.
- `src/audio/sfx.ts`: procedural WebAudio. `playSfx(name, {amount, gain})` for bubble, coin, splash, bell, clack, click, open, close, error, fanfare, sparkle, gull, cheer. `setTrainSpeed(v)` runs the da-dum clack rhythm. Each sound has a minimum gap, so bulk event bursts don't pile up.
- `src/audio/index.ts`: `createAudio(bus, getSettings, {getLine})` → `GameAudio`. It unlocks on the first pointerdown, keydown or touchend.
  - Event map: purchase → bubble · levelUp → sparkle · milestone → fanfare · fare → coin(amount) · arrive → bell (+ Line scene) · depart → gull (50%) · frenzy → splash + cheer · bondFormed / requestCompleted → cheer · sightStart whale* → whale song (ducks) · lineOpened → fanfare + scene · depotReset → fanfare + scene(new line) · ending → `enterEnding()` · settings → volumes · openPanel 'depot' → Depot theme · uiSound (coin/click/open/close/error).
  - During the ending, `music_ending` plays and game SFX are ducked by −9 dB.
- `src/ui/video/cinematic.ts` + `video.css`: `playCinematic(container, name, {loop, onEnd, lowQuality, stillSeconds, still})` loads `/video/<name>.{webm,mp4}` with poster `<name>.jpg`. It is muted, plays inline, and only plays files that exist (checked with `hasFile`). If the file is missing, fails to load, or quality is Low, it shows the still key art (title/ending/line_cover_n) with a CSS Ken-Burns pan instead. `playLineSplash(container, line, {lineName, region, lowQuality, seconds, onEnd})` plays the `line_<n>` clip with a Line name card; a tap dismisses it.
- `src/ui/ending/{ending.ts,ending.css,timeline.ts}` + `src/render/ending/{layer.ts,beach.ts,underwater.ts,owned.ts}`: `runEnding({container, api?, renderer?, fish?, lowQuality?, audio?, onDone})`. ## Wiring snippet for T-13 (main.ts)
```ts
import { createAudio } from './audio';
import { runEnding } from './ui/ending/ending';
import { playCinematic, playLineSplash } from './ui/video/cinematic';

const audio = createAudio(game.bus, () => api.getSettings(), { getLine: () => game.sim.state.currentLine });
// per frame, from the train render (world units/s, 0 when stopped):
audio.setTrainSpeed(trainSpeed);
// Depot panel closed → back to the Line music:
audio.backToLine();          // (opening it is automatic via bus 'openPanel' {id:'depot'}; call audio.setScene({kind:'depot'}) if the UI opens it another way)
// a feed tap (no sim event exists for plain feeding):
audio.playSfx('splash');

// Grand Terminus (sim emits 'ending'; audio already switched to the ending theme):
game.bus.on('ending', () => {
  api.setPaused?.(true);
  runEnding({ container: document.body, api, audio, onDone: () => api.setPaused?.(false) /* endless mode toast: story ending.endlessToast */ });
});

// Title screen background loop (behind T-14's title):
const titleCine = playCinematic(titleEl, 'title_loop', { loop: true, lowQuality: quality === 'low' });
// … titleCine.stop() when the title closes.

// Line opening splash:
game.bus.on('lineOpened', (e) => {
  const l = game.data.lines.find((x) => x.id === e.line);
  playLineSplash(document.body, e.line, { lineName: l?.name ?? `Line ${e.line}`, region: l?.region, lowQuality: quality === 'low' });
});
```
Notes: `uiSound` is already emitted by the UI through `api.emitUi` on the same bus, so nothing to wire there. Quality 'auto' → pass `lowQuality: true` when the stage decided Low.
