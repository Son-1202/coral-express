## Diagnosis

- **Offline (accepted deviation, see TUNING.md).** 5.9% (offline median 60.6 vs 64.4; reached 100.0%). One 8 h break at 50% (70% with Season Pass) is a lump of ~4–5.6 h of the income at minute 30, early in the first Line 2 run. In this economy income grows exponentially (e-fold every ~1–1.5 min), so a lump of N seconds of income saves only ≈ P·ln(N/P) ≈ 5–7 min, and only in the current run: Resets are Ticket-bound (projected ≥ 2× total) and the reset count is structural (4), so later runs are unchanged. Reaching 15–35% would need offline to carry across resets (a rule change outside T-20), or an offline rate/cap far beyond the SPEC.
- **Dominance (accepted deviation, see TUNING.md).** 58.9% (p10 35.6%, p90 81.1%); resets over 35%: 91.5%. Species output grows ~×5 per station tier while a level only adds +1× (milestones ×2 at 10/25/50), so the newest tier earns most of a run's fish income at its end. The top species differs by run (counts of resets over 35%: snow_crab 1700, watchman_goby 1126, pistol_shrimp 532, icefish 300), so no species carries the session; the replay runs start with the previous run's top fish as Mascot, whose species is in the Catalogue. Flattening it would mean re-shaping the whole tier ladder (basePps ratios), not tuning.

## Definitions

- **Meaningful goal**: new species this run, carriage, extra slot, track, bond formed, milestone, request completed, Today's Special, terminal, line opened, Depot Reset becoming available, reset, upgrade. Gap = longest stretch between goals inside minutes 5–15 of each run (window edges count).
- **Dead time**: longest stretch (after minute 1) with no spending action (fish, level, carriage, slot, decor, habitat, track, special, upgrade); a stall at the end of a game that never reaches the Terminus counts.
- **Income at min 15**: average run Shells/s over the 60 s before minute 15 of run 1 (or before the first reset if it comes earlier).
- **Dominance**: share of the run's fish income (`state.speciesShells`) earned by the top species, sampled right before each reset.
- Fare / request shares are of all Shells earned in the game (fish + fares + sights + requests + offline).
- **Species bought** (T-20, PM): the Grand Terminus signature species (pocket_whale) is excluded — it is sold only at the Terminus itself, as the endless-mode reward. The greedy bot buys a terminal's signature species before taking the Depot Reset when it can afford it within 60 s (the market stays open at the depot).
- **Bots (T-20)**: Mascot = highest-output fish; greedy keeps Shells to build the next track before the train leaves the last built station when that track repays within 150 s; bond-never avoids cars holding a bond partner when it can (the no-bonds baseline).
